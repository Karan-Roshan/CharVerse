# CharVerse — Custom NFT Character Collection Website
CharVerse is a modern, responsive web application showcasing a **unique NFT character collection**. This project is designed for creators, collectors, and NFT enthusiasts to explore, create, and connect with exclusive digital characters in a visually appealing layout. Built using **HTML5** and **CSS3**, CharVerse emphasizes aesthetics, usability, and smooth navigation.


## Project Overview
CharVerse focuses on presenting a **digital NFT character collection** with interactive cards, detailed project info, roadmap, FAQs, and call-to-action sections for users to create and view their own NFTs. This project can be used as a landing page for NFT projects or digital art collections.

Key Highlights:
- Responsive design for desktops and mobiles
- Interactive hover effects for NFT cards
- Integrated social links and call-to-action buttons
- Sectioned layout: Hero, Cards, Collection, Project, Roadmap, Join Us, FAQ, Footer


## Features
- **Hero Section:** Engaging intro with headline, description, and CTA buttons.
- **Character Cards:** Hover effects with details and links for each NFT.
- **Collection Section:** Showcases top characters with pricing info.
- **Project Section:** Explains the NFT project concept and minting process.
- **Roadmap Section:** Step-by-step plan for the NFT collection.
- **Join Us Section:** Encourages users to create their own NFTs.
- **FAQ Section:** Provides answers to common questions.
- **Footer Section:** Includes site links, company info, and social icons.
- **Responsive Design:** Works seamlessly on all devices.


## Tech Stack
- **HTML5** — Semantic structure  
- **CSS3** — Custom styling, Flexbox, responsive layout, hover effects  
- **Font Awesome** — Social media and icon integration  
- **Google Fonts** — Typography: Lora & Roboto
